Rejected LZ decode match-copy experiment
Date: 2026-11-09

The experiment replaced repeated `Vec::extend_from_within` calls with direct writes into spare output capacity using `copy_nonoverlapping` and prefix doubling. Round trips and fuzz tests passed, but the lane-decode medians did not show a verified improvement, so the unsafe kernel was removed and the original safe copy path retained.

Criterion used 10 samples, 0.1 s warm-up, 0.15 s requested measurement on the AVX2 host. These are separate runs and should be read as exploratory, not a paired benchmark.
