CODE PATH AND COST MODEL
The fast entropy prefilter samples 64 evenly spaced 32-byte windows (2,048 input bytes total) for each lane at least 4 KiB. Its fixed scratch is 256 x u16 byte counters (512 B) plus 4,096 x u32 exact 3-gram slots (16,384 B), or 16,896 B on the stack; work is O(1) in input length. It bypasses LZ only when byte diversity is high and repeated 3-grams are nearly absent. The mixed 1 MiB random/periodic test verifies that a large repetitive region prevents bypass.
The parallel gate is a 16,384-byte aggregate-input comparison. Single-lane horizontal work uses 64 KiB blocks, 64 KiB of prior history, and at most 130 bytes of lookahead as borrowed slices. At 1 MiB this is 16 jobs and about 960 KiB of history re-hashing in addition to the 1 MiB of block data; asymptotic work remains O(n), with a roughly 2x hash-input constant for large inputs. No block directory or other per-block serialized bytes are added. Measurements show <=+0.03% parallel size delta in this file corpus.
Each wide-hash worker allocates a 2^18-entry u32 head table (1,048,576 B) and a 2^16-entry u32 history-link ring (262,144 B): 1,310,720 B of these two tables per active worker, plus touched-head and token/literal buffers. Sixteen concurrent jobs therefore have a 20 MiB lower bound for those two tables alone. This trades scratch/cache pressure for throughput; the reported 1 MiB compressible case is 4.35x faster than serial. It is not a no-heap/cache-resident guarantee.

CPU ASSEMBLY INSPECTION
The optimized bench assembly was emitted with cargo rustc --bench files --profile bench --offline --locked -- --emit=asm and the resulting Windows x86_64 executable was disassembled with LLVM objdump. The actual 4-way interleave path contains 32-byte vmovdqu loads followed by four AVX2 vpshufb operations, vextracti128, vpunpckldq, and vmovq stores; the hot loop advances by eight records. RNBW's AVX2 match extension also emits vpcmpeqb and vpmovmskb compare sequences. The LZ hash-chain loop remains scalar and dependent: multiplicative hash (imull), head/previous loads, 65,536-byte distance check, and up to 32 chain probes.
For code comparison only, the cached lz4_flex 0.14.0 block source was separately emitted as optimized assembly. Its main compress_internal loop likewise performs a scalar multiplicative hash, loads a 16-bit table position, checks the 64 KiB distance, then extends matches; LZ4 remains a benchmark-only comparator in RNBW. This separate assembly build is not a benchmark timing and may differ in compiler flags from the Criterion dependency build.
No instruction-count claim is inferred from the source alone. Assembly explains that AVX2 accelerates field splitting and match extension, while dependent hash-chain lookup and entropy coding remain the RNBW encode cost centers.
