RNBW Huffman decode fast-table experiment: encode, decode, roundtrip
Date: 2026-11-09

Change kept: a 10-bit prefix lookup table inside canonical Huffman decode. The on-disk format and encoder are unchanged. Codes <=10 bits use one table lookup; codes >10 bits and short input tails retain the validated bit-at-a-time fallback. The decoder creates a fixed 1,024-entry u16 table (2,048 bytes) on the stack per active decode call; added format bytes: 0; added heap allocation: 0. Setup is O(1,024 + number of short-code expansions), then O(output bytes) for short codes, with the existing O(code length) fallback for long codes.

Benchmark method: Criterion optimized profile, AVX2 selected, 10 samples, 100 ms warmup and 150 ms target measurement per case. Baseline is the full general-corpus run before the change; final run measures all RNBW encode/decode IDs on the same 16 datasets. These are separate runs, not interleaved paired samples. Values below are Criterion median point estimates; complete confidence intervals are in the raw logs.
Baseline raw log: general-encode-decode-current-2026-11-09.txt
Final RNBW-only raw log (includes roundtrip cases): general-rnbw-encode-decode-fastpath-2026-11-09.txt

Summary: RNBW hybrid decode geomean speedup 1.421x (CI non-overlap: 11 faster, 1 slower, 4 overlap, out of 16). Parallel-form decode geomean 1.453x (CI non-overlap: 12 faster, 2 slower, 2 overlap). Encode source is unchanged: one-shot geomean 0.971x (CI non-overlap 0/2/14 faster/slower/overlap); reuse-serial 1.003x (7/5/4); reuse-parallel 1.012x (3/2/11). Encode timing movement is run noise, not a claimed improvement.

Rejected encode-side experiment: replacing the canonical symbol builder's repeated alphabet scans with scattered one-pass bucket writes produced 0.927x geomean reuse-parallel encode speed (1.0 means no change) on the first full A/B; Criterion intervals showed it slower in 11 cases, faster in 2, and overlapping in 3. That code was reverted. The initial encode/decode capture logs are retained as evidence: general-encode-huffman-lookup-2026-11-09.txt and general-decode-huffman-lookup-2026-11-09.txt.
