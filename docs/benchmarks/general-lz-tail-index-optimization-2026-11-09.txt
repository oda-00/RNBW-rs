# RNBW LZ match-index tail optimization

Date: 2026-11-09

## Change

After accepted matches longer than 48 bytes, the encoder indexes only the final 16 byte positions. Shorter matches keep the original complete indexing. For a 130-byte match this removes 113 hash calculations and table inserts (87.6%) while preserving recent match candidates. It adds no scratch memory or serialized bytes; the 32-bit match-token/literal-stream format, entropy coding, 64 KiB window and block boundaries are unchanged. The decoder is unchanged.

## Benchmark method

Paired baseline and candidate: Criterion, 20 samples per case, 150 ms warm-up, 250 ms target measurement, all 16 general corpus cases. Each case includes serial/parallel encode, decode and serial/parallel roundtrip. Candidate roundtrip assertions validate the decoded bytes. Times below are medians in microseconds; positive delta means candidate is faster. Raw logs preserve Criterion intervals.

Baseline: `general-lz-tail-confirm-baseline-2026-11-09.txt`. Candidate: `general-lz-tail-threshold-48-candidate-2026-11-09.txt`.

Roundtrip is the end-to-end guard against an invalid stream. Exact encoded size is unchanged on 13/16 cases; native executable changes by +448 bytes serial / −368 bytes parallel in these paired runs, repository Rust source by +64/+72 bytes, and generated prose by −120/-136 bytes serial/parallel. The other 13 cases are byte-identical in the paired captures.

## Correctness and tooling

`cargo fmt --all --check` and `cargo test --offline --locked` passed on the selected threshold: 46 library tests, 3 binary tests, codec mutation fuzz, and all 3 TRNMAP mutation fuzz tests. The Criterion harness also validates complete RNBW roundtrips for all 16 general corpus cases. Runtime dispatch selected AVX2. Hyperfine, Valgrind/Callgrind, and cargo-flamegraph are unavailable in this Windows environment; the host processor model could not be queried.

All raw exploration captures (tail lengths 4/8/16/32 and thresholds 17/48/96) are retained in `docs/benchmarks/`. The measured choice is tail 16, skip threshold 48: it keeps strong long-match encode wins while avoiding the clearer natural-prose and JSON regression seen at threshold 96.
