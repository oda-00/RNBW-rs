RNBW general file codec + undecoded TRNMAP index benchmark (fixed corpus, retained code)
Date: 2026-11-09
Run: cargo bench --offline --locked --bench files -- --sample-size 10 --warm-up-time 0.1 --measurement-time 0.15 --noplot --quiet
Criterion timed 10 samples per group; it extended measurement time for several slow groups. Timings are medians. Host reported AVX2.
Corpus: 16 general workloads. Every codec was round-trip checked against the exact original bytes before timing. RNBW decode is full decode; copy-on-write borrowed cases are separately labeled and excluded from full decode comparisons.
Corpus repeatability: native executable, repository Rust source, repository technical prose, and WGSL sources are frozen in benches/data. The native executable input is a checked-in Windows PE snapshot of the benchmark driver. Generated corpora use fixed seeds.
TRNMAP is a separate raw little-endian-u32 position-to-class index (zero, high-bit-set nonzero, other nonzero), built over the same raw corpus. It is not inside the compression codec and does not decode compressed streams.
