# L1 mask construction fusion A/B

Candidate committed as `34f21c2`. It replaces per-level full-key scans with one outer traversal that loads each key once for mask construction and updates each selected level in an inner loop. L1 image layout and wire bytes are unchanged; a randomized reference-equivalence test compares every level mask against the former algorithm for all even widths 2–32.

Criterion command: `cargo bench --offline --locked --bench store -- store-build --sample-size 10 --warm-up-time 1 --measurement-time 2`. Each dataset has 1,000,000 keys. Baselines are Criterion stored references on this host; the Criterion change report was emitted during the candidate run.

### Cost model

The removed mask stage performed D input scans for N keys, with D≤16; the fixed-width asymptotic bound remains O(N·D)=O(N). The candidate performs one input load per key in the outer mask pass and D mask updates per key. Bucket-stream and low-bit construction still read the source separately. Serialized mask/rank/bucket bytes are unchanged.

Peak logical mask scratch changes from `8 × max_l ceil(nodes[l]/16)` bytes (reused vector) to `8 × Σ_l ceil(nodes[l]/16)` bytes (all level masks live together), an increase of `8 × (Σ_l ceil(nodes[l]/16) − max_l ceil(nodes[l]/16))` bytes, plus allocator capacity. Candidate Massif is being captured by the GitHub workflow; WSL resource limits prevented a second local launch after the baseline profile.

### Validation

`cargo fmt --all -- --check`, `cargo clippy --offline --locked --all-targets -- -D warnings`, and `cargo test --offline --locked` passed. The test suite had 58 tests including deterministic mutation fuzzing; the new test compared fused masks against the prior per-level reference over 16 widths and 12 randomized sets per width, for every depth.
